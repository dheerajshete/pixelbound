# 🎮 PIXELBOUND

**A 2D Pixel-Art Platformer Built with Python and Pygame**

Welcome to **PIXELBOUND**, a 2D platformer game developed using Python and Pygame. Explore the world, defeat zombies, improve your score, and challenge yourself across different difficulty levels.

## 🚀 Features

- 🎮 Player movement and animations
- 🏃 Running, jumping and falling
- ⚔️ Attack system
- 🧟 Zombie enemies
- 🎯 Collision detection
- 🌍 Scrolling game world
- ⭐ Score and high-score system
- ⚙️ Easy, Medium and Hard difficulty levels
- 👤 Player profile system
- 💾 Save and load settings
- 🎵 Background music
- 🖥️ Custom main menu and settings screens

## 📥 Download and Play

**Latest Release: PIXELBOUND V3**

1. Visit the [Releases](../../releases) page.
2. Download `PIXELBOUND.zip`.
3. Extract the ZIP file.
4. Open the extracted `PIXELBOUND` folder.
5. Double-click `PIXELBOUND.exe`.

No separate Python installation is required.
